# LingoPop

Aplicación unificada de aprendizaje de idiomas con misiones, narrativa y exploración.

- **Versión actual:** 3.0 beta (home narrativo, tres idiomas y Paris Pop)
- **Web:** https://lingopop-academia.vercel.app
- **Versiones anteriores:** `versions/`
- **Fuentes Android/iOS:** `mobile/`

El contenido de `versions/` conserva versiones históricas para referencia. La raíz contiene la versión web/PWA más reciente. Android/iOS requieren compilación y firma antes de publicarse en tiendas.

> Estado: prototipo educativo y 3D beta; las ilustraciones conceptuales no equivalen a assets 3D finales.
