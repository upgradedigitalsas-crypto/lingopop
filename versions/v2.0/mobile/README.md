# LingoPop 2.0 | Juego y aprendizaje unificados

Una sola aplicación para web, Android e iOS. El juego es la interfaz principal y los cursos están integrados directamente en sus personajes, diálogos, microdesafíos y progresión. No se requieren servicios de IA ni claves externas para jugar.

## Ejecutar
```
npm install
npm run sync
npm run android:open  # Android Studio
npm run ios:open      # Xcode en Mac
```

**Antes de tiendas:** terminar pruebas nativas, firma, política de privacidad, capturas fieles de dispositivo, y la información legal de la cuenta desarrolladora.

**Notas:** el escenario 3D utiliza WebGL con fallback Canvas2D. Aún no dispone de los modelos GLB detallados de la ilustración conceptual; la calidad final requiere modelado y animación profesional. El progreso se guarda localmente y migra los datos anteriores de Academia y World si siguen en el mismo dispositivo.
