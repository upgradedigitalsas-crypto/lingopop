# LingoPop 2.0 — Una sola aventura educativa

LingoPop no separa Academia y World: la aplicación comienza en una ciudad explorable; cada día de los tres idiomas se convierte en una misión de un personaje. Incluye 90 lecciones originales, vocabulario y audios mediante síntesis del dispositivo, tres preguntas y un objetivo final. Cada recompensa registra XP y fecha en la clave previa `lingua30_multilingue_v1` para conservar los progresos existentes.

- Idiomas: francés (Paris Pop), inglés (London Pop), portugués brasileño (Rio Pop).
- Modo principal: WebGL 3D procedimental y fallback Canvas2D.
- Controles: teclado, joystick táctil y tocar suelo.
- La aplicación es local-first y no tiene chat de IA.
- Google Play y App Store todavía requieren compilación, firma y revisión.
- El arte 3D es un primer escenario estilizado creado por código, no reproduce fielmente la imagen conceptual de calidad AAA.
